# Excel_Projects_Data_Analytics
# 📊 Data Science & Data Analytics Job Market Analysis

An Excel-based data analytics project exploring **data-related job salaries, required skills, job types, and geographic differences**.

This project contains two complementary Excel workbooks. The first focuses on analyzing relationships between salaries and skills, while the second provides an interactive dashboard for exploring salary information across different job-market segments.

---

## 📁 Project Files

### 1. `1_Project_Analysis.xlsx`

This workbook focuses on analyzing the relationship between **job roles, salaries, and skills**.

### 2. `1_Salary_Dashboard.xlsx`

This workbook contains an **interactive salary dashboard** built from a dataset of approximately **32,672 job postings**.

---

# 📊 Salary Dashboard

The `1_Salary_Dashboard.xlsx` workbook provides an interactive way to explore salary information across different job titles, countries, and employment types.

Users can filter the dashboard by:

- **Job Title**
- **Country**
- **Employment Type**

The dashboard dynamically displays:

- Median Salary
- Job Count
- Top Job Platform
- Salary by Job Role
- Salary by Employment Type
- Geographic salary information
